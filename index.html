Using Randomization & Stratification to Overcome a Common Cause Confounder

Understanding Surgical Outcomes Beyond Surface-Level Data

Introduction

When evaluating performance using observational data, it is easy to draw misleading conclusions. Apparent differences in outcomes may not reflect true causal effects but instead arise from hidden confounding variables.

This report examines the performance of two surgeons—Doc Dreamy and Doc Duck—and demonstrates how confounding, randomization, and stratification influence our interpretation of data.

Observational Data: A Misleading Conclusion

We begin with observational data, where patients were not randomly assigned to surgeons.

import pandas as pd
import matplotlib.pyplot as plt

patients_df = pd.read_csv('patients_data.csv')

# Color palette
dreamy_color = '#4E79A7'
duck_color = '#E15759'

# Split data
dreamy = patients_df[patients_df['doctor_name'] == 'Doc Dreamy']
duck = patients_df[patients_df['doctor_name'] == 'Doc Duck']

# Compute means
dreamy_mean = dreamy['post_surgical_score'].mean()
duck_mean = duck['post_surgical_score'].mean()

# Create figure
fig, ax = plt.subplots(figsize=(10, 6))

# Scatter plots
ax.scatter(dreamy['patient'], dreamy['post_surgical_score'],
           color=dreamy_color, marker='o', label='Doc Dreamy', alpha=0.8)

ax.scatter(duck['patient'], duck['post_surgical_score'],
           color=duck_color, marker='^', label='Doc Duck', alpha=0.8)

# Mean lines
ax.axhline(dreamy_mean, color=dreamy_color, linestyle='--', linewidth=2)
ax.axhline(duck_mean, color=duck_color, linestyle='--', linewidth=2)

# Annotations
ax.text(5, dreamy_mean + 0.1, f'○ Mean: {dreamy_mean:.2f}', color=dreamy_color)
ax.text(5, duck_mean + 0.1, f'△ Mean: {duck_mean:.2f}', color=duck_color)

# Labels and styling
ax.set_title("Post-Surgical Symptom Score by Patient and Doctor", fontsize=14)
ax.set_xlabel("Patient Number")
ax.set_ylabel("Post-Surgical Symptom Score (Lower is Better)")
ax.grid(alpha=0.3)
ax.legend()

plt.show()

Interpretation

At first glance, Doc Dreamy appears to outperform Doc Duck. His patients show lower average post-surgical scores, suggesting better outcomes.

However, this conclusion is misleading.

The Role of Confounding

Patient severity acts as a hidden confounder. Patients with milder conditions tend to choose Doc Dreamy, while more severe cases are disproportionately treated by Doc Duck.

This imbalance creates the illusion that Doc Dreamy performs better, when in reality, the comparison is not fair.

Randomization: Revealing the True Effect

To remove this bias, patients are randomly assigned to surgeons.

patients_randomized_df = pd.read_csv('patients_data_randomized.csv')

# Split data
dreamy_r = patients_randomized_df[patients_randomized_df['doctor_name'] == 'Doc Dreamy']
duck_r = patients_randomized_df[patients_randomized_df['doctor_name'] == 'Doc Duck']

# Means
dreamy_mean_r = dreamy_r['post_surgical_score'].mean()
duck_mean_r = duck_r['post_surgical_score'].mean()

# Plot
fig, ax = plt.subplots(figsize=(10, 6))

ax.scatter(dreamy_r['patient'], dreamy_r['post_surgical_score'],
           color=dreamy_color, marker='o', label='Doc Dreamy', alpha=0.8)

ax.scatter(duck_r['patient'], duck_r['post_surgical_score'],
           color=duck_color, marker='^', label='Doc Duck', alpha=0.8)

ax.axhline(dreamy_mean_r, color=dreamy_color, linestyle='--', linewidth=2)
ax.axhline(duck_mean_r, color=duck_color, linestyle='--', linewidth=2)

ax.text(5, dreamy_mean_r + 0.1, f'○ Mean: {dreamy_mean_r:.2f}', color=dreamy_color)
ax.text(5, duck_mean_r + 0.1, f'△ Mean: {duck_mean_r:.2f}', color=duck_color)

ax.set_title("Post-Surgical Symptom Score (Randomized Assignment)", fontsize=14)
ax.set_xlabel("Patient Number")
ax.set_ylabel("Post-Surgical Symptom Score (Lower is Better)")
ax.grid(alpha=0.3)
ax.legend()

plt.show()

Interpretation

Once randomization removes the confounding effect, the results reverse:

  • Doc Duck now shows better outcomes.
  • The earlier conclusion was driven by biased patient assignment.

Randomization reveals the true causal relationship.

Stratification: A Practical Alternative

When randomization is not feasible, stratification offers a powerful alternative.

# Means (reuse observational data)
fig, ax = plt.subplots(figsize=(10, 6))

ax.scatter(dreamy['severity'], dreamy['post_surgical_score'],
           color=dreamy_color, marker='o', label='Doc Dreamy', alpha=0.8)

ax.scatter(duck['severity'], duck['post_surgical_score'],
           color=duck_color, marker='^', label='Doc Duck', alpha=0.8)

# Mean lines
ax.axhline(dreamy_mean, color=dreamy_color, linestyle='--', linewidth=2)
ax.axhline(duck_mean, color=duck_color, linestyle='--', linewidth=2)

# Highlight overlap region
ax.axvspan(-1, 1, alpha=0.15, color='gray', zorder=0)

# Annotations
ax.text(-2.5, dreamy_mean + 0.1, f'○ Mean: {dreamy_mean:.2f}', color=dreamy_color)
ax.text(-2.5, duck_mean + 0.1, f'△ Mean: {duck_mean:.2f}', color=duck_color)

# Labels
ax.set_title("Post-Surgical Symptom Score by Patient Severity", fontsize=14)
ax.set_xlabel("Initial Patient Severity")
ax.set_ylabel("Post-Surgical Symptom Score (Lower is Better)")
ax.grid(alpha=0.3)
ax.legend()

plt.show()

Interpretation

Within the overlapping severity range:

  • Doc Duck consistently achieves better outcomes.
  • The apparent advantage of Doc Dreamy disappears.

Stratification allows us to compare like with like, revealing the same insight as randomization.

Conclusion

This analysis highlights a critical lesson:

  • Observational data can mislead.
  • Confounding variables can create false conclusions.
  • Randomization provides causal clarity.
  • Stratification offers a practical alternative.

What initially appeared to be a clear victory for Doc Dreamy turns out to be an illusion. Once we account for patient severity, it becomes evident that Doc Duck is the better surgeon.

Understanding the structure behind the data—not just the numbers—is essential for making sound decisions.
